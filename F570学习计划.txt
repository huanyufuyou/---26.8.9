F570 四旋翼 8 周学习计划
==================================================

一、目标（带走什么）
--------------------------------------------------
1. 手搓飞控（作品）
2. 可移植 FreeRTOS 模板（模块）
3. LQR 控制经验可迁移（能力，到小车/多旋翼）
4. 内容清晰（学习笔记，数据流图/参数表收进笔记当章节）

二、手搓边界
--------------------------------------------------
- 控制链手搓：姿态环 + 位置环 + 电调输出 + FreeRTOS 任务编排 + 五层架构
- IMU 解算：读透原厂代码、画出公式与数据流、写进笔记（不重写）

三、里程碑（8 周）
--------------------------------------------------
分段：
- 暑假密集期（约 4 周）：15~20h/周，目标 = M1 全过 + M2 拿下
- 开学后收尾（约 4 周）：10h/周，目标 = M3

M1（暑假第 1~2 周）：
- 编译烧录跑通（蓝牙/数据线直刷）
- 无桨桌面试验：油门标定、电机方向、上电顺序、PID 反应方向
- 数据流图完成、笔记开篇

M2（暑假第 3~4 周，开学前必须拿下）：
- 五层重写 PID 悬停环
- 系留悬停姿态收敛 ±2°
- FreeRTOS 模板 F570 侧跑通（任务 + 队列 + 中断桥最小例程）

M3（开学后 4 周）：
- 系留/自由飞稳定悬停 ≥30 秒
- LQR（仿真）vs PID 对比结论
- FreeRTOS 模板搬到小车工程跑通（搬得动才叫可移植）
- 笔记完稿

四、试飞与安全
--------------------------------------------------
- 路径：无桨桌面试验 → 装桨系留（重物锚点）→ 自由飞（学校空地）
- 每阶段固定最小安全清单：急停 / 桨保护 / 上电顺序，逐条打勾
- 每次改控制环之前，先保存一个"能飞的基线固件"
- 光流场地检查清单：纹理 / 光照 / 地面材质
- 安全三步不允许跳步，物理收敛时间不可压缩

五、任务级
--------------------------------------------------
- 五层架构 L5 任务层 + 自动任务状态机（起飞/悬停/降落/返航）

六、LQR 线
--------------------------------------------------
- 数学够用：线代已学完特征值/对角化，Riccati 方程的地基在
- MATLAB 从零上手：以"MATLAB 搭四旋翼模型 + LQR 仿真"为第一个实际问题
- 8 周内 LQR 只到仿真 + 对比结论；实机 LQR 后置为延伸目标

七、节奏与协作
--------------------------------------------------
- 暑假密集期 15~20h/周（约 4 周）+ 开学后 10h/周（约 4 周）
- 人 + AI 混合：AI 讲透 / 审 / 追踪进度；自己写核心 / 读手册 / 看 B 站 / 试飞
- 手搓部分以自己写为主（AI 不代写）
- 进度随能力与其他计划灵活调整

八、启动现实
--------------------------------------------------
- 先解决编译/烧录（Keil + 蓝牙/数据线直刷），再谈飞行与改环
- 无台架、无 3D 打印机 → 无桨桌面试验 + 系留重物锚点方案
- 室内无场地 → 电脑前的代码/仿真工作在家完成，验证才出门
